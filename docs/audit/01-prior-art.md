# 01 — Prior art: bug classes from resolved issues of comparable projects

Mined 2026-10-04 with `gh issue list --state closed --search …` over Warp,
xterm.js, Wails, Tabby, Wave, WezTerm, Hyper and Svelte. Rows are kept only
when the class plausibly applies to Mimir's stack (Svelte 5 legacy mode,
xterm.js 6 with fit/search/clipboard addons and the DOM renderer, Wails v2 on
WebKitGTK/WebView2, split panes, tmux "invisible" mode, SSH/SFTP). Links point
to the source issue; nothing is copied. "Mimir area" names the component from
`00-surface-map.md`; "check" is what a domain agent should actually do.

Facts about Mimir used for the mapping (verified by reading the code, not
changed): `app/frontend/package.json` lists only `@xterm/addon-fit`,
`addon-search`, `addon-clipboard` — there is **no** webgl and **no**
unicode11 addon in the frontend (the surface map's addon list is wider than
the dependency list). `main.go` sets `EnableDefaultContextMenu: true` and
`BackgroundColour` 27/38/54 (`#1b2636`) while `XTERM_THEME.background` and
`--bg-void` are `#0c0e14`. `AppMainContent.svelte` renders pages with
`{#if currentPage === …}` so `TerminalsPage` is unmounted on every page
switch and re-attached by `reinitializeTerminals()`.

## Top 15 checks for Mimir (likelihood × impact)

1. **Browser default context menu with "Reload"** — `main.go` `EnableDefaultContextMenu: true`, only panes handle `contextmenu`; right-click on sidebar/header offers Reload, which drops every xterm and in-memory state (Wails [#2438](https://github.com/wailsapp/wails/issues/2438), [#5518](https://github.com/wailsapp/wails/issues/5518)). Area: `main.go:82`, `App.svelte`.
2. **Page switch unmounts all terminals** — `AppMainContent.svelte` `{#if currentPage === "terminals"}` → detach/re-attach via `reinitializeTerminals()`; check blank panes, lost scroll position, duplicate DOM wiring, and focus after Settings → Terminals (Tabby [#11213](https://github.com/Eugeny/tabby/issues/11213), [#729](https://github.com/Eugeny/tabby/issues/729)).
3. **Store churn per output chunk** — `terminalActions.js:233–244` replaces the whole `terminals` list and slices a 12 kB buffer on every PTY chunk and sends a transcript IPC; every `$:` consumer re-runs. Profile with 6 panes and fast output (Hyper [#1456](https://github.com/vercel/hyper/issues/1456), Warp [#8089](https://github.com/warpdotdev/Warp/issues/8089)).
4. **Search is not incremental and highlights nothing** — `terminalSearchActions.js` calls `findNext(query)` without `{incremental: true, decorations}`; each keystroke jumps to a new match, no highlight-all, slow at 100 000 lines (xterm [#1653](https://github.com/xtermjs/xterm.js/issues/1653), [#3830](https://github.com/xtermjs/xterm.js/issues/3830), [#5176](https://github.com/xtermjs/xterm.js/issues/5176)).
5. **300 ms PTY resize debounce vs immediate xterm reflow** — `RESIZE_SETTLE_MS` keeps program width ≠ xterm width during drags; check junk rows pushed into scrollback and cursor placement after reflow (xterm [#4639](https://github.com/xtermjs/xterm.js/issues/4639), [#5295](https://github.com/xtermjs/xterm.js/issues/5295); WezTerm [#1512](https://github.com/wezterm/wezterm/issues/1512)).
6. **Unicode width without unicode11 addon** — not in `package.json`; CJK/emoji/ZWJ alignment, search offsets and the resize-with-wide-chars crash class (xterm [#4753](https://github.com/xtermjs/xterm.js/issues/4753), [#3527](https://github.com/xtermjs/xterm.js/issues/3527); Warp [#13040](https://github.com/warpdotdev/Warp/issues/13040)).
7. **Shortcuts keyed on `event.key` letters** — `keyboardShortcuts.js:172/179` accept only uppercase `N`/`F`; CapsLock, Cyrillic/Greek layouts and IME composition (`isComposing`, keyCode 229) break Ctrl+Shift+N/F and can fire shortcuts mid-composition (Warp [#3812](https://github.com/warpdotdev/Warp/issues/3812), xterm [#6067](https://github.com/xtermjs/xterm.js/issues/6067)).
8. **Ctrl+wheel zoom steps per event** — `SplitPane.svelte` `handleTerminalWheel` zooms one step per wheel event without delta accumulation; a touchpad gesture or pinch runs 13 → 28 at once (Tabby [#184](https://github.com/Eugeny/tabby/issues/184), Hyper [#345](https://github.com/vercel/hyper/issues/345)).
9. **`GTK_IM_MODULE=gtk-im-context-simple` forced on Linux** — `inputmethod_linux.go` fixes dead keys but disables ibus/fcitx for users who did not export the variable; CJK input impossible (Warp [#9383](https://github.com/warpdotdev/Warp/issues/9383), [#11815](https://github.com/warpdotdev/Warp/issues/11815); WezTerm [#5125](https://github.com/wezterm/wezterm/issues/5125)).
10. **Reconnect UX and hard-coded English** — `SplitPane.svelte:537–541` `'Reconnecting...'`/`'Reconnect'` and `FileBrowser.svelte` errors bypass `$t`; verify `reconnecting` resets on failure and scrollback survives (Tabby [#4673](https://github.com/Eugeny/tabby/issues/4673), [#8812](https://github.com/Eugeny/tabby/issues/8812)).
11. **Window background colour mismatch** — `main.go` `BackgroundColour` `#1b2636` vs `--bg-void`/`XTERM_THEME.background` `#0c0e14`: visible flash at launch and during resize on WebKitGTK/WebView2 (Wails [#2852](https://github.com/wailsapp/wails/issues/2852), [#1655](https://github.com/wailsapp/wails/issues/1655)).
12. **DPR changes without CSS size change** — ResizeObserver never fires when moving between 100 %/150 % monitors or after lock/unlock; glyph metrics and `lineHeight: 1.35` rounding at 125 % (Wails [#5677](https://github.com/wailsapp/wails/issues/5677), [#5544](https://github.com/wailsapp/wails/issues/5544); Warp [#13124](https://github.com/warpdotdev/Warp/issues/13124); xterm [#967](https://github.com/xtermjs/xterm.js/issues/967)).
13. **No confirmation when closing a busy pane; close re-inits everything** — no `confirm` for working agent or live SSH; `terminal-closed` and manual close call `reinitializeTerminals()` over all terminals (Warp [#2717](https://github.com/warpdotdev/Warp/issues/2717); Tabby [#2801](https://github.com/Eugeny/tabby/issues/2801), [#11124](https://github.com/Eugeny/tabby/issues/11124); WezTerm [#5304](https://github.com/wezterm/wezterm/issues/5304)).
14. **Legacy `$:` side-effect chains in `AgentTranscriptPanel.svelte`** — 33 reactive statements including `view = 'snippets'` self-assignments (118/143/144) and `setInterval`/`clearInterval` inside `$:` (88–91); check for `effect_update_depth_exceeded`, leaked timers and stale tabs under Svelte 5 batching (Svelte [#6732](https://github.com/sveltejs/svelte/issues/6732), [#13635](https://github.com/sveltejs/svelte/issues/13635)).
15. **Windows shell integration overwrites the user's prompt** — `terminalActions.js` runs `function prompt {…}; cls` / `prompt … & cls` on every PowerShell/cmd terminal, discarding oh-my-posh/Starship; plus CRLF paste behaviour (Warp [#4316](https://github.com/warpdotdev/Warp/issues/4316), [#7479](https://github.com/warpdotdev/Warp/issues/7479)).
